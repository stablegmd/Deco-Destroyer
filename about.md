# Deco Destroyer

**Destroy decoration. Preserve gameplay.**

Deco Destroyer is a Geometry Dash editor utility that makes turning decorated levels into clean layouts incredibly simple.

With a single button, remove unwanted decoration and visual clutter without manually selecting thousands of objects.

## Features

- One-click decoration removal.
- Preserves important gameplay objects.
- Removes visual-only triggers.
- Optional object recolouring.
- Customisable settings.
